# Support

VFS365 is free software. Support is not free.

## Free, best effort

- **Bug reports and feature ideas**: open an [issue](../../issues). We read every issue, but there is no response time, and we decide what gets fixed and when.
- **Documentation**: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) covers installation, policies, antivirus, monitoring and troubleshooting; [docs/APP-REGISTRATION.md](docs/APP-REGISTRATION.md) covers consent and your own app registration.

Issues are not a helpdesk: questions about your own environment, deployment or configuration will be closed with a pointer here.

## Paid support

JSolve B.V. offers help with deploying and running VFS365, troubleshooting in your tenant, priority fixes, and changes or features for your organisation.

- https://jsolve.nl/hire.html

## When you report a bug

Include the VFS365 version (`vfs365.exe about`), the Windows version and architecture, the WinFsp version, how you deployed (setup, MSI, Intune) and the relevant lines from `%LOCALAPPDATA%\VFS365\agent.log`. Remove user names, tenant names and file paths you don't want to publish first.
